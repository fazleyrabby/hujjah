# Hujjah — Handover Prompt (2026-04-29)

## What is Hujjah

Free, open-source Islamic reference app (offline-first). Two targets:
- **`apps/web`** — Next.js web app (primary, deployed). User tests via friends. **Priority.**
- **`apps/tauri`** — Tauri desktop app (secondary, same UI codebase). Fix after web is stable.

Both share two SQLite databases (symlinked from tauri → web):
- `hujjah-quran.db` — Quran, translations, tafsir, embeddings
- `hujjah-hadith-core.db` — Hadiths, translations, narrators, chains, embeddings

Current branch: **`sunnah-migration`** (not yet pushed — user runs `git push origin sunnah-migration` manually via SSH).
